<h1>문자열 덧셈 계산기</h1>
<hr>

### 1. 개요
- 입력된 문자열에서 숫자를 추출하여 모두 더한 값을 반환하는 계산기입니다.

---
### 2.기능 요구 사항
1. **기본 구분자**는 쉼표 `,` 와 콜론 `:` 입니다.
   - 예: `"1,2:3"` → 1+2+6 = `6`
2. 입력이 빈 문자열(`""`)이면 `0`을 반환합니다.
3. **커스텀 구분자**는 입력의 앞부분 `//<구분자>\n<숫자들>` 형식으로 지정합니다.
   - 커스텀 구분자는 **기본 구분자에 추가로 허용**.
   - 예: `"//?\n1?2:3"` → `6`, `"//!\n1!2,3:4"` → `10`
4. **잘못된 값 입력** 시`IllegalArgumentException`을 발생시킨 후 종료됩니다.

---
### 3. 구현 기능 목록

1. **기본 구분자 처리**
   - 쉼표(,), 콜론(:)을 기준으로 숫자를 분리 후 합산

2. **사용자 커스텀 구분자 지원**
   - 문자열 앞부분에 `//[구분자]\n` 형식으로 새로운 구분자 지정 가능

3. **빈 문자열 처리**
   - 입력이 `""` (빈 문자열)일 경우 결과는 `0`

4. **입력 검증**
   - 잘못된 구문이 존재할 경우 예외 발생.

### ⚠️예외 규칙
| 구분             | 규칙/원인 | 대표 잘못된 입력                                     |
|----------------|---|-----------------------------------------------|
| 커스텀 헤더 형식 오류   | 커스텀은 `//<구분자>\n<본문>` 형식(구분자 1문자, 줄바꿈 `\n`) | `//\n1;2`, `//;\r1;2`, `//;1;2`, `//;;\n1;2`  |
| 빈 토큰(연속/선두/후미) | 숫자 사이에 **빈 값** 존재 불가 | `1,,2`, `//;\n1;;3`, `,1,2`                   | 
| 비숫자 토큰         | 각 토큰은 **정수**여야 함 | `1,a,3`                                       |
| 본문 없음/형식 불일치   | 헤더만 있고 본문이 없거나 제어문자 등 비정상 | `//;\n`                                       |
| 음수 토큰          | 음수는 허용하지 않음 | `"-1,2:3"`, `"//;\n1;-2;3"`                   |
| 커스텀되지 않은 구분자   | **기본 `, :` 또는 헤더로 선언된 커스텀** 외의 구분자 사용 금지 | `"1;2:3"` (커스텀 미선언), `"//;\n1;2?3"` (`?` 미선언) |


---
### 4. 프로그래밍 요구 사항
- 버전은 **JDK 21**
- 프로그램 실행의 시작점은 **`Application`의 `main()`**.
- **`build.gradle` 파일은 변경 불가**, 제공된 라이브러리 외 **외부 라이브러리 사용 금지**.
- 프로그램 종료 시 **`System.exit()` 호출 금지**.

---
### 5. 입출력 요구 사항

#### 📥 입력
- 구분자와 양수로 구성된 문자열을 입력받습니다.

#### 📤 출력
- 입력된 숫자의 **덧셈 결과**를 출력합니다.

---

### 6. 실행 결과 예시

####  💡 예시 1) 기본 구분자 사용
```

1,2:3  
결과 : 6
```

#### 💡 예시 2) 커스텀 구분자 사용

```
덧셈할 문자열을 입력해 주세요.  
//;\n1;2;3  
결과 : 6
```
#### 💡 예시 3) 빈 문자열 입력
```
덧셈할 문자열을 입력해 주세요.  
결과 : 0
```
